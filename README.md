## Caveat — supervised scores on synthetic data

The Layer 3 supervised detector (`d5a_training.py` / `d5b_inference.py`) trains on
`data/warmup_labeled_transactions.csv`, which is itself generated by System 1 with the same
typology injectors that populate the historical / stream sets. On synthetic data the supervised
score can look deceptively high because the classifier is partly learning the **injection
signature** — features that any sample produced by the same generator shares.

This is exactly what makes Layer 3 the highest-precision layer on synthetic data and also why
it should not be read as evidence of real-world generalisation. The unsupervised layers
(Layer 4 behavioural anomaly, Layer 5 TGN / GNN) provide the more honest demonstration: they
never see labels, so their performance reflects how well the topology and behavioural
structure transfer to truly unseen patterns.

`hidden_ground_truth.csv` remains **sealed**: it is consumed only by System 3 (evaluation)
and never read by any detector. Layer 3 only ever sees the warmup labels.
